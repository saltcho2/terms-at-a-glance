## 1. 실제로 확인한 사실

일반 Chrome 브라우저에서 공개 사이트를 새로고침했을 때 데이터 로딩 실패는 재현되지 않았습니다. 검색 전에는 서비스 상세와 빈 결과 안내가 숨겨졌고, JavaScript 필요 안내도 화면에 나타나지 않았습니다. 수정 전 실제 화면의 집계도 등록 500개·요약 제공 154개 서비스 251개 항목·사례 19건이었습니다. 이 관찰을 모든 방문자·모든 환경에 대한 정상 보장으로 확대하지 않습니다.

반면 초기 HTML에는 숨겨진 상세 영역에 `YouTube`와 `youtube.com · 5개 핵심 항목`이 남아 있었습니다. 이 오래된 기본값은 실제 소스에서 확인해 제거했습니다. 텍스트만 추출하는 환경에서 숨김 요소나 noscript 내용을 함께 읽었을 가능성은 있으나, 사용자가 본 환경을 직접 조사하지 않아 원인을 단정하지 않습니다.

자산 4개는 모두 실제 브라우저에서 `/terms-at-a-glance/` 아래 URL로 해석됐습니다. `/data.json` 같은 도메인 루트 절대 경로를 사용하는 문제는 발견하지 못했습니다.

## 2. 수정 파일과 변경 내용

| `service-catalog.js` | 네이버 콘텐츠 항목과 Netflix 해지 항목의 적용 범위 설명만 추가. 요약·확인일·사례 수는 임의 갱신하지 않음 |

| `qa-20261017/check-phase2.mjs` | 코드 검사 26개. 실제 브라우저 결과와 별도 집계 |
| `qa-20261017/phase2-code-tests.json` | 코드 검사 결과 |
| `qa-20261017/phase2-live-tests.json` | 실제 배포 화면·별도 실패 주입 프레임의 관찰 결과 |

`data-app-state`는 loading, home, result, no-results, empty-query, pending, failed로 구분합니다. 단순 상태 식별과 렌더링 정리이며 별도의 대규모 프레임워크를 도입하지 않았습니다.

## 3. 집계 기준과 실제 값

| 지표 | 기준 | 실제 값 |
|---|---|---|
| 등록 서비스 | 현재 카탈로그의 서비스 레코드 수 | 500개 |
| 요약 제공 서비스 | 표시할 요약 항목이 1개 이상 있는 서비스 | 154개 |
| 원문 대조 기록이 있는 항목 | 원문 URL·문서명·조항 위치·지역·대조일 기록을 가진 항목 | 251개 |
| 재확인 안내 항목 | 대조 후 30일 초과 또는 대조일이 없거나 유효하지 않음 | 0개 |
| 요약 없는 서비스 | 등록됐으나 표시할 요약이 없는 서비스. 공식 링크만 확인한 경우도 포함 | 346개 |
| 실제 사례 | 현재 사례 데이터의 등록 레코드 수 | 19건 |

`원문 대조 기록`은 기록의 존재를 집계하며 이번에 251개를 모두 재검수했다는 뜻이 아닙니다. `재확인 0개`도 원문이 변경되지 않았다는 뜻이 아닙니다. 기존 대조일들이 30일 이내여서 해당 안내 대상이 없다는 의미입니다. 925개 주소의 과거 접속 점검 기록은 이번 화면 집계와 구분했습니다.

사례 안내는 0건이면 “아직 등록된 사례가 없습니다.”, 1~3건이면 “등록된 사례 N건”, 3건 초과이면 “최근 사례 3건 · 전체 N건”, 자료가 없거나 구조가 잘못됐으면 “사례 목록을 불러오지 못했습니다.”와 “집계 불가”로 표시합니다.

### 발견한 실패와 후속 수정

첫 번째 빠른 추천 연속 클릭 검사에서 Netflix를 눌렀는데 YouTube가 유지되는 현상을 1회 관찰했습니다. Netflix 단독 클릭은 정상 작동했습니다. 화면 이동 애니메이션의 간섭 가능성이 있어 선택 후 부드러운 스크롤을 제거했고, 수정 배포 후 같은 5개 연속 클릭을 재실행했을 때 모두 정상 전환됐습니다. 이 재검증은 해당 시나리오의 결과이며 모든 입력·기기에서 경합이 없음을 증명하지는 않습니다.

## 7. 아직 검증하지 않은 부분과 남은 위험

- 모바일 실기기, 느린 회선에서 로딩 화면의 시간 경과, JavaScript를 실제로 끈 브라우저, 화면 읽기 프로그램 전체 경로는 이번에 검증하지 않았습니다.
- 정상 사이트에서 로딩 실패가 자연 발생하는 현상은 이 환경에서 재현되지 않았습니다. 사용자 기기의 캐시·확장 프로그램·접속 환경을 확인한 결과가 아닙니다.
- 별도 실패 주입 테스트를 운영 환경에서의 자연 장애 재현 또는 전 브라우저 복구 보장으로 보고하지 않습니다.
- 실제 사용자 테스트 참여자는 0명입니다. 5명 사용자 테스트 완료로 보고하지 않습니다.
- 전체 약관 재검수, 전체 원문 링크 재점검, 사례 전체 최신 상태 재검증, 자동 약관 변경 감지, 법률 전문가 검토는 수행하지 않았습니다.
- 데이터 생성 스크립트를 재실행할 경우 최근 운영 데이터 수정이 유지되는지 파이프라인 검증은 별도 과제로 남습니다.

## 8. 다음 우선순위

1. 실제 휴대전화·사용자 접속 환경에서 동일 검색·재시도 시나리오를 실행하고 통신 로그를 확보합니다.
2. 신규 사용자 5명에게 검색·핵심 조건·원문·최신성 안내를 찾는 과제를 주고 이해도와 소요 시간을 기록합니다.
3. 아직 표본으로 대조하지 않은 고영향 약관 항목과 개별 서비스 추가 약관을 검수합니다.
4. 생성 입력과 운영 데이터의 일치를 확인한 후 정기 검수·변경 추적 운영을 설계합니다.
