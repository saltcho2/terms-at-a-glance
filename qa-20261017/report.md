## 1. 실제 확인한 사실

- 10개 서비스를 선정하여 서비스마다 1개 항목, 총 10개 항목을 공식 원문과 대조했습니다. YouTube와 동일한 원문·요약을 쓰는 Google 1개 항목도 함께 확인해 수정했습니다. 합계 11개 서비스의 11개 항목이며, 서비스 전체 검수가 아닙니다.
- 표본의 출처 유형은 약관·개인정보처리방침 8개, 공식 도움말 2개(Netflix·Notion)입니다. 도움말을 약관 원문으로 취급하지 않았습니다.
- 공식 주소, 표시된 조항 위치, 적용 범위, 짧은 인용, 확인 가능한 날짜, 편집 요약과 이용자 영향을 대조했습니다. 위법성 판단이나 법률 전문가 검수는 수행하지 않았습니다.

- 2026-10-17의 원문 열람은 변경 감지 시스템의 작동 결과가 아니라 이번 표본 조사입니다. 날짜가 최근이라는 사실만으로 그 이후의 원문 불변을 보장하지 않습니다.

- 원문 변경 자동 감지·버전 차이 비교는 없습니다. 30일 이내에도 원문은 변경될 수 있습니다. 오래된 표시를 붙이는 것만으로 이를 해결하지 못합니다.
- Spotify·Steam 등 날짜를 확보하지 못한 문서는 시행일·게시일이 여전히 미확인입니다. 외국어 문서의 한국 이용자 적용 여부와 현지법의 우선 적용은 법률 검토가 필요합니다.
- Netflix·Notion 도움말은 계약 문서 전체를 대체하지 않습니다. Netflix 국가 선택에 따른 세부 조건, Notion 기능별 추가 계약도 미검증입니다.
- 실제 모바일 화면·네트워크 장애·스크린리더·전체 접근성 검사는 미실시입니다. 일부 키보드·색상 검사 결과를 전체 적합성으로 확대 해석하지 않습니다.
- 원문 10개는 공식 자료 열람으로 확인했으나, 브라우저 클릭 도착 확인은 GitHub 1개입니다. 925개 URL 전체 유효성 검사가 아닙니다.
- 초기화 이후의 예외, 부분 손상 데이터, 통신 재시도·캐시 충돌은 이번 실패 분기 테스트로 모두 보장되지 않습니다.
- 기존 데이터 생성 스크립트를 재실행하면 이번 운영 데이터 수정이 덮어써질 수 있습니다. 생성 파이프라인을 통합·재검증하기 전에는 무작정 재생성하지 마세요. 이번 기록과 변경 커밋을 대조 기준으로 사용하세요.

## 8. 다음 작업 우선순위

1. 실제 휴대전화에서 360~430px 화면의 검색·필터·상세·원문 링크를 테스트하고, 브라우저 요청 차단으로 로딩 실패를 재현합니다.
2. 실제 신규 사용자 5명을 확보해 위 과제의 성공률·소요 시간·최신성 오해를 기록합니다.
3. 240개 미재검수 항목에서 결제·환불·콘텐츠 권리 항목을 우선 표본 확대하고, 중복 원문을 공유하는 항목의 불일치를 점검합니다.
4. 현재 운영 데이터와 생성 스크립트의 입력을 일치시키고, 검수 기록 보존 검사를 배포 전 필수로 연결합니다.
5. 위 항목을 마친 뒤 원문 변경 감지와 정기 재검수 운영을 설계합니다. 현재 완료된 기능으로 표시하지 않습니다.
