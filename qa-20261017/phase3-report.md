## 전수 점검 범위와 한계

등록 500개 서비스의 저장된 후보 주소 972개를 점검했습니다. 954개 초기 주소에 요청을 시도했고, 호스트 제한 후 후속 주소 18개는 요청하지 않았습니다. 본문 스냅샷 수집 633개, 수집 불가 339개입니다. 이 수치는 HTTP 리다이렉트·하위 리소스를 합친 서버 요청 수가 아니며, 후보 주소의 공식성·조항 해석 검수를 뜻하지 않습니다. 실패한 서비스나 항목을 삭제하지 않았습니다.

요약 251개 항목의 근거 필드를 전수 점검했습니다. 문서·조항 위치·지역·대조일 기록은 있지만, 직접 인용 기록은 12개이며 239개에는 없습니다. 시행일 미기록 156개, 게시일 미기록 249개입니다. 원문에 날짜가 없을 수도 있으므로 누락을 곧바로 내용 오류로 판정하거나 날짜를 임의로 채우지 않았습니다. 요약 없는 346개 서비스와 항목별 보완 목록을 `full-evidence-audit.json`에 남겼습니다.

**전체 약관의 내용 재검수는 미완료입니다.** 앞선 10월 17일 표본 11개 항목과 이번 Google 두 번째 항목의 대조를 전체 500개 서비스 검수로 확대해 보고하지 않습니다. 기존 대조 기록이 있다는 사실도 이번 재검수 완료로 취급하지 않습니다.

`.github/workflows/policy-monitor.yml`로 현재 공개 링크 157개의 본문 스냅샷을 매일 비교합니다. 예약은 UTC 20:17(한국 시간 다음 날 05:17)이며 GitHub 실행 지연 가능성이 있습니다. 두 차례 실제 실행 성공을 확인했습니다.

- 첫 실행: https://github.com/saltcho2/terms-at-a-glance/actions/runs/39128182168
- 후속 실행: https://github.com/saltcho2/terms-at-a-glance/actions/runs/39128448663
- 후속 기록: 동일 스냅샷 120개, 차이 감지 7개, 수집 실패 30개.
- 원문 수집, 테스트, 결과 커밋, Pages 빌드 요청 단계가 모두 성공했습니다.

차이가 감지되면 다음 실행에 동일하게 나와도 재검수 대기 상태를 유지합니다. 수집 실패는 변경 없음으로 처리하지 않습니다. 화면의 재확인 집계는 날짜 경과·날짜 기록 부재·스냅샷 차이·수집 실패를 반영합니다. 확인일을 수집일로 덮어쓰지 않습니다. 기준 스냅샷을 갱신하려면 담당자가 실제 조항을 재대조하고 별도 검수 기록과 함께 커밋해야 합니다.

HTML 본문 비교는 레이아웃·지역별 내용에도 영향을 받을 수 있습니다. 따라서 **자동 약관 개정 확정이나 자동 요약 검수 기능은 아닙니다.** 변경 조항의 의미 비교, 이전 전체 원문 열람 UI, PDF·동적 페이지의 본문 비교는 구현하지 않았습니다. 기존 스크립트 입력 `audit-original-catalog-20261009.json`은 잘린 JSON으로 파싱되지 않아 재생성에 사용하지 않았습니다. 향후 데이터 생성 파이프라인 정비가 필요합니다.

## 실제 실행한 검사

코드: `node qa-20261017/check-phase2.mjs` 30개 통과. `python scripts/test_policy_sources.py` 2개 통과. 모니터의 기준 생성→동일→차이→차이 유지→실패→복구 상태와 탐색 메뉴 제외·본문 차이 보존을 검사했습니다. 이는 법률 검수나 실제 사용자 테스트가 아닙니다.

배포 Chrome에서 직접 확인:

| 과제 | 결과 |
|---|---|
| 새로고침 | 검색 전 home, 가짜 기본 상세 없음. 500/154/251/346/19 집계 유지 |
| Google 검색 | 두 항목 표시. 시행일 수정과 원문 스냅샷 차이·재대조 안내 표시 |

| 파일 누락과 재시도 | 404 리소스 기록, 검색 실패 안내. 재시도 후 새 문서 시작 시각과 404 재관측 |

요청 계측은 별도 배포 검증 페이지의 Resource Timing입니다. 정상 초기화에서 스크립트 5개(200)와 별도의 HTML fetch 1회를 관측했습니다. 선택 후 로고 요청 1개가 추가됐습니다. 정상 스크립트 transferSize가 0으로 캐시 사용이 관측됐습니다. 누락 파일은 404, transferSize 300으로 재시도 전후 각각 관측했고 문서 시작 시각도 달라졌습니다. 원시 기록: `phase3-http-observations.json`. 서버 로그 전체 요청 수·실기기 통신량은 측정하지 않았습니다.
