# 홈 화면 재구성 — 2026-10-18

## 변경 범위
- 첫 화면을 소개·검색 중심으로 재구성하고, 약관을 읽을 때 확인할 네 가지 질문을 본문 중심에 배치.
- 기존 ‘어떤 내용을 확인할 수 있나요?’의 서비스 요약 카드 세 개 제거. 사건 사례와 요약이 같은 카드처럼 보이는 구조 해소.
- 실제 사례는 별도 섹션에 기존 데이터 기준 최근 세 건 표시. 사례·원문·검색 연결 유지.
- 자료 집계는 펼침 영역으로 이동. 등록 수, 요약 제공 수, 대조 항목 수 등 집계 기준 유지.
- 정리 기준과 공식 원문 접근 경로 유지. 기존 카드 대신 작은 원문 링크 목록 제공.
- 홈페이지 전용 CSS 분리. 서비스 데이터, 사례 데이터, 검색 엔진과 상세 기능은 재작성하지 않음.

## 코드 검증
기존 Node 회귀 검사 30개 통과. 중복 ID 없음, 홈의 네 가지 주제와 원문 링크 세 개, 정본 데이터와 정적 원문 링크 일치 검사 통과.

브라우저 검증은 배포 후 별도 기록. 물리적 휴대전화 및 실제 사용자 테스트 결과를 뜻하지 않음.

## 실제 배포 검증
- 홈 질문 4개, 실제 사례 3개 표시. 기존 서비스 요약 카드 없음.
- PC 문서 폭 1348px, 스크롤 폭 1348px. 360px 프레임의 문서 폭 345px. 관측 시 가로 넘침 없음.
- 추천 Netflix 선택 시 상세 2개 항목 표시. 홈 소개·본문은 상세에서 숨김. 홈 버튼 복귀 및 본문 검색 링크 이동 확인.
- 미등록 검색 결과 안내와 추가 요청 경로 표시 확인.
- Tab으로 검색 버튼 이동 시 포커스 테두리 확인. 자료 현황은 Enter로 펼침·접힘 확인.
- 실제 집계 500개 등록·156개 요약 제공·19건 사례 확인.
- 오류 주입 프레임에서 검색 자료 실패 안내, 검색 숨김, 공식 원문 링크 3개 유지 확인. 사례 0건은 ‘아직 등록된 사례가 없습니다.’로 구분.
- 홈 CSS와 스크립트 총 6개 Resource Timing 항목의 200 응답 관측. 서버 로그의 전체 HTTP 요청 수를 뜻하지 않음.
- 물리적 휴대전화, 실제 사용자 실험, 전체 접근성 검사는 수행하지 않음.
